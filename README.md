# Training

A single-file mobile workout sheet. Open it on your phone and each exercise shows the name, the sets × reps, one weight, and a notes box. No account and no server.

**Live app:** https://duss48.github.io/Training-app/

## Your data stays on this phone

The weight and notes for each exercise are saved in this browser's localStorage. They belong to the exercise, not to a date. They stay on that phone, in that browser. Clearing site data, or opening the app in another browser, does not bring them with it.

Use the **Data** tab's JSON export (Download JSON backup or Copy JSON) as your backup. Import that file from the same tab to restore. An older backup still imports. Set-by-set logs stay in the saved data (they are not shown on the sheet), and the latest weight for an exercise is kept when that exercise does not already have one.

A program update does not erase that save. Missing warm-up lines are added, and a replaced exercise keeps its id, weight, note, and any older logs. The new form cue is shown on that exercise. Days, exercises, and warm-up lines you edited stay in place.

## Add to your iPhone home screen

1. Open https://duss48.github.io/Training-app/ in **Safari**.
2. Tap **Share**.
3. Tap **Add to Home Screen**.

The home-screen icon opens the sheet full screen.
