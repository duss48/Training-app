# Training

A single-file mobile workout tracker. It runs entirely in the browser: log sets, rest, notes, and cardio days with no account and no server.

**Live app:** https://duss48.github.io/Training-app/

## Your data stays on this phone

Workouts are saved in this browser’s localStorage. They stay on that phone, in that browser. Clearing site data, or opening the app in another browser, does not bring the logs with it.

Use the **Data** tab’s JSON export (Download JSON backup or Copy JSON) as your backup. Import that file from the same tab to restore.

## Add to your iPhone home screen

1. Open https://duss48.github.io/Training-app/ in **Safari**.
2. Tap **Share**.
3. Tap **Add to Home Screen**.

The home-screen icon opens the tracker full screen.
